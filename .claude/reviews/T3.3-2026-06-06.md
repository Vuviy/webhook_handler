## Seam review (focus 1 — types only, backward-compatible)
Confirmed the production change is a pure testability seam with **no behaviour change**:
- `QueueInterface` (`scheduleRetry`/`deadLetter`/`promoteDueRetries`) and `EventWriter` (`markForRetry`/`markFailed`) declare exactly the method signatures already present on `Queue` and `EventRepository`; both classes now `implements` them with no body edits.
- `RetryScheduler` only **widened** its dependency types (`Queue`→`QueueInterface`, `EventRepository`→`EventWriter`). Widening a parameter type to a supertype is backward-compatible: `worker.php:77` `new RetryScheduler($queue)` still passes a real `Queue` (which `implements QueueInterface`), and `worker.php:148/173/179/185` still pass a real `EventRepository` (which `implements EventWriter`). `DlqRequeue` does not construct or call `RetryScheduler`. Verified `phpunit` green proves the runtime still satisfies the interfaces.
